Виды движения

Основные виды механического движения.

→ Равномерное

Тело за одинаковые промежутки времени проходит одинаковые расстояния. Скорость постоянна.

↗ Равноускоренное

Скорость тела изменяется на одинаковую величину за равные промежутки времени.

◯ Движение по окружности

Траектория движения представляет собой окружность. Направление скорости постоянно изменяется.

⌁ Криволинейное

Теория

Основные понятия и формулы по теме механического движения.

Механическое движение

Механическое движение — изменение положения тела относительно других тел с течением времени.

Траектория

Траектория — линия, по которой движется тело. Она может быть прямолинейной или криволинейной.

Путь

Путь — длина траектории, пройденной телом.

s = v · t

Скорость

Скорость показывает, какое расстояние тело проходит за единицу времени.

v = s / t

Ускорение

Ускорение показывает скорость изменения скорости тела.

a = (v - v₀) / t

Равноускоренное движение

При постоянном ускорении скорость тела изменяется равномерно.

v = v₀ + at
s = v₀t + at² / 2

Свободное падение

У поверхности Земли ускорение свободного падения приблизительно равно:

g ≈ 9,8 м/с²

Движение по окружности

При движении по окружности вектор мгновенной скорости направлен по касательной, а центростремительное ускорение — к центру окружности.

a = v² / R
